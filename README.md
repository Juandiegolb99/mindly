# Mindly

Aplicación local para Windows para organizar ideas con tableros libres, notas, imágenes, escritura a mano, ecuaciones y documentos anotados.

## Descargar e instalar

Descarga **Instalar-Mindly-Windows.exe** desde [la última versión](https://github.com/Juandiegolb99/mindly/releases/latest), ejecútalo y pulsa **Instalar y abrir**. Requiere Microsoft Edge instalado.

En una instalación nueva se abre **Empieza con Mindly**, un proyecto editable con ejercicios de notas, tableros, imágenes, dibujo, fórmulas, tareas y tablas. El instalador incluye **Empieza-con-Mindly.mindly**. Puedes recuperarlo desde **Proyectos → Abrir ejemplo** o **Proyectos → Descargar ejemplo**.

## Guardar tus proyectos

Crea proyectos independientes desde **Proyectos**. Usa **Guardar archivo** para obtener un archivo .mindly que puedes trasladar y abrir en otro equipo con Mindly. Guarda una copia de tus cambios antes de compartir el archivo.

El guardado local y tus archivos permanecen en tu equipo. Las vistas previas de enlaces pueden consultar el sitio enlazado y metadatos de Crossref.
